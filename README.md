## 🚀 Simulation Tasks & Solutions

### Task 1: Phishing Email Analysis & Defensive Strategy
* **Objective:** Analyze a suspected corporate phishing email targeting Mastercard employees and propose technical countermeasures.
* **What I Did:** 
  * Inspected suspicious email headers, analyzing sender domains and verifying SPF, DKIM, and DMARC alignments.
  * Identified indicators of compromise (IoCs) including mismatched display names and malicious URLs.
* **Deliverable:** Created a comprehensive Phishing Analysis Report detailing threat indicators and immediate mitigation steps (`/task-1-phishing-analysis/`).

### Task 2: Firewall Security Optimization
* **Objective:** Review and optimize network infrastructure security by updating firewall rules to block malicious traffic while maintaining business continuity.
* **What I Did:** 
  * Analyzed simulated network logs to isolate traffic coming from malicious IP ranges.
  * Drafted a set of strict inbound and outbound Access Control Lists (ACLs) using the principle of least privilege.
* **Deliverable:** A documented list of optimized firewall rules (`/task-2-firewall-configuration/firewall_rules.txt`).

### Task 3: Enterprise Security Awareness Design
* **Objective:** Formulate a strategic security awareness guide to educate internal Mastercard teams on emerging social engineering threats.
* **What I Did:** Developed a scannable, actionable framework detailing how non-technical departments can identify vishing, smishing, and physical tailgating attempts.
